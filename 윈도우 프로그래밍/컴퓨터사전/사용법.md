# 컴퓨터 용어사전2 사용법

## 1. 용어 검색
1. 상단의 **입력란**에 검색할 용어를 입력합니다.
2. **검색** 버튼을 클릭합니다.
3. 결과 출력 영역에 해당 용어의 뜻이 표시됩니다.
   - 사전에 없는 용어인 경우 `사전에 없는 용어입니다.` 메시지가 표시됩니다.

## 2. 단어 등록
1. 상단의 **입력란**에 등록할 용어를 입력합니다.
2. 하단의 **"등록할 뜻을 입력하세요:"** 아래 텍스트 영역에 뜻을 입력합니다.
3. **단어 등록** 버튼을 클릭합니다.
4. 등록이 완료되면 결과 출력 영역에 등록 완료 메시지가 표시됩니다.

### 주의사항
- 용어와 뜻을 모두 입력해야 등록이 가능합니다. 비어있으면 경고 메시지가 나타납니다.
- 이미 등록된 용어를 다시 등록하려 하면 덮어쓸지 확인하는 대화상자가 나타납니다.
- 등록된 단어는 프로그램 실행 중에만 유지되며, 프로그램을 종료하면 초기화됩니다.
